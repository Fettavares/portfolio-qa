# Projeto 01 — Testes Manuais | SauceDemo

## Objetivo
Realizar testes funcionais em uma aplicação de e-commerce, validando os principais fluxos do usuário.

## Funcionalidades a testar
- Login
- Listagem de produtos
- Carrinho de compras
- Checkout
- Logout

## Tipos de teste
- Testes funcionais
- Testes positivos e negativos
- Testes exploratórios
- Testes de regressão
